# Native design contract

Generated concept boards were removed from the repository and are not implementation assets. No generated anime character or catalogue image may be bundled in the native app.

## Phone

- Preserve AniGhost's live mobile identity: compact ghost/sign-in header, tall cinematic hero, pink `Watch now`, restrained metadata, genre strip, Continue Watching, New Episodes, and the floating dark navigation island.
- Navigation is `Home · Search · Manga · Saved · Profile`.
- Search appears once: selecting Search in the island opens the search screen. Home does not repeat a search field.
- Anime and manga imagery comes from the native API's highest-resolution backend URL, rendered with memory-and-disk caching and crop rules appropriate to the destination.

## TV

- Use a slim left rail, full widescreen hero, one dominant resume/watch action, one save action, Continue Watching, and a small set of curated shelves.
- D-pad focus is unmistakable and stable. Focused artwork may scale gently only when the source can remain sharp at the focused size.
- TV streams and resumes; offline download management remains contextual to phone playback.
